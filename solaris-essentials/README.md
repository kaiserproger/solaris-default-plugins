# Solaris Essentials

**Deployment: Server-only.** Commands work from an ordinary vanilla client: bounded durable homes and warps/spawn, same-dimension `/back`, tick-timed `/tpa` + `/tpaccept`, and `/msg` + `/reply`.

Names are lowercase letters, digits, `_`, or `-`. `/setspawn`, `/setwarp`, and `/delwarp` require a Solaris operator. `/home` and `/sethome` require the `solaris.essentials.use` node, and `/setwarp`/`/delwarp` require `solaris.essentials.manage`, whenever the deployment provides a permission provider (`solaris-permissions`); the operator check still applies afterwards. `/back` remembers deaths and successful teleports initiated by this plugin; component API 0.8 does not publish arbitrary teleport/movement history. Homes, warps/spawn, `/back`, and TPA retain the destination dimension. Cross-dimension teleports are refused with a message naming the destination dimension; they never reuse its coordinates in the player's current world. The host checks the destination dimension again when committing, so a dimension change during an asynchronous storage lookup cannot move the player into the wrong world. Old v1 saved locations have an unknown dimension and must be saved again with `/sethome` or `/setwarp`; editing another location preserves their unknown status instead of guessing. TPA and private-message name lookup includes only currently online players and rejects ambiguous names.
