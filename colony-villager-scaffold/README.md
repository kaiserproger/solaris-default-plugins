# Colony Villager Scaffold

**Deployment: Server-only.** No Solaris Loader is required; an ordinary vanilla 26.1.2 client can use this plugin.

This API `0.6.0` example keeps colony identity, roles, orders, and durable intent in Luau/plugin storage. Rust receives only generic zone, villager-binding, and villager-goal requests. Copy the directory into the configured plugin root or enable the bundled id `colony-villager-scaffold`.
